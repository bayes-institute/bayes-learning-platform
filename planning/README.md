# Planning

This is the project’s working planning area. It is intentionally separate from implementation code so decisions, open questions and next actions can evolve without being mistaken for application behaviour.

## Files

| File | Purpose |
| --- | --- |
| [01_CLOUD_RUN_CLIENT_SERVER_DEPLOYMENT.md](01_CLOUD_RUN_CLIENT_SERVER_DEPLOYMENT.md) | Current self-followed implementation runbook: refactor handoff, Google Cloud bootstrap, two Cloud Run services, GitHub Actions CI/CD, verification, rollback and cost controls. |
| [__archive__](./__archive__) | Earlier deployment, data-model and next-step notes retained as historical working material. The numbered runbook is the current starting point. |

## Working rule

Record a decision with its reason and date when it affects cost, security, data access, or a public API. Keep uncertain ideas in the relevant “open questions” section until they are decided. Do not put credentials, service-account JSON, private URLs or real user data in this folder.
